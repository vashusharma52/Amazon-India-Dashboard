# 📊 Amazon India Sales Dashboard

## 📌 Project Overview
This project presents an Amazon India Sales Dashboard created
using Microsoft Excel. It analyzes sales data and displays
important business metrics through charts and visualizations.

## 🎯 Project Objective
The objective of this project is to analyze Amazon India sales
data and understand overall sales performance, profitability,
product performance, and order status.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Dashboard Visualization

## 📈 Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Profit Margin

## 📊 Dashboard Features
- Category-wise Sales Analysis
- Category-wise Profit Analysis
- Top 5 Products by Sales
- Order Status Distribution
- Sales and Profit Performance

## 💡 Key Learnings
- Data analysis using Microsoft Excel

- Building an interactive dashboard
- Presenting business insights visually
